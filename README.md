# Omar Design System Skill (`omar-design-system`)

Reusable AI agent skill distilling Omar Farook's (`@buildwithomar`) anti-AI-slop design methodology, state-first HTML scratch prototyping, parameter-slider tuning, scroll-beat storytelling, and multi-agent UI orchestration.

## Install

```bash
npx skills add <owner>/omar-design-system
```

Or copy the repository contents into your agent's `skills/omar-design-system/` folder.

## Structure

- `SKILL.md`: Primary agent trigger and step-by-step workflow
- `references/anti-slop-checklist.md`: Component rules for navbars, heroes, forms, dashboards, cards, buttons, icons, and AI states
- `references/scratch-file-protocol.md`: State-first HTML mockup and live range-slider tuning rules
- `references/scroll-beat-and-motion.md`: 4-beat scroll storytelling and WebKit/Chromium smoothness rules
- `references/agent-orchestration-and-handoff.md`: Boss/worker delegation and design-system-as-Markdown conventions
- `assets/scratch-template.html`: Single-file HTML starter with state switcher and live CSS variable sliders
